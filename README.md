# Frostbay。

一方寒海，一点暖光。轻轻触碰，让北极醒来。

**Frostbay** 是一个可交互的微型北极立体模型。整个应用包含在一个自包含的 `index.html` 中，使用原生 **WebGPU / WGSL** 渲染；所有几何、天气与水体均程序生成，没有外部库、导入模型、图片纹理或运行时网络请求。

## 运行

使用支持 WebGPU 的新版 Chrome、Edge 或 Safari，并开启硬件加速。

可以直接用浏览器打开 `index.html`。如果浏览器限制本地文件的 WebGPU，或希望通过本地服务器运行：

```bash
git clone https://github.com/huihui200739/frostbay.git
cd frostbay
python3 -m http.server 8000 --bind 127.0.0.1
```

然后打开 <http://localhost:8000>。不需要安装任何项目依赖。

WebGPU 不可用时，页面会显示明确的后备提示卡片。

## 交互

| 操作 | 效果 |
| --- | --- |
| 按压海面 | 形成柔软的深凹陷与体积中性的隆起边缘 |
| 按住并拖动海面 | 移动柱塞，留下实际模拟的三维尾流；悬停不会产生波浪 |
| 拖动橙色皮划艇 | 带着尾流移动；被拿着时不会倾覆，强烈局部波浪可能使其倒置 |
| 拖动玻璃侧面 | 海水块在果冻基座上倾斜、滑动、晃回，并产生晃荡 |
| 拉动果冻边缘 | 局部拉伸，然后由阻尼弹簧复位 |
| 空白区域拖动 | 轨道旋转相机；Shift + 拖动也可旋转 |
| 鼠标滚轮 / 双指捏合 | 缩放 |
| “呼唤鲸鱼” / 双击或双击触摸 | 鲸鱼浮起、喷雾、甩尾潜水 |
| 天气面板 | 日光、阴天降雪、极光之夜，以及独立的暴风雪开关 |
| 暂停 / 重置 / 复位视角 | 冻结模拟；恢复海水、块、海豹与正位小艇；恢复相机 |

键盘快捷键：`Space` 暂停或继续，`W` 呼唤鲸鱼，`R` 重置（画布获得焦点时）。

## 场景与生命

- 清澈的长方形寒海块、圆润闪亮的冰蓝 / 淡薰衣草色果冻基座。
- 雪覆盖的岩石岛屿、潮汐岩层、玻璃处的岩芯横截面与海底巨石。
- 交错弧形雪砖冰屋、入口隧道、琥珀色冰窗与暖光。
- 木板码头、柱子、灯笼、红白旗帜、双叶桨皮划艇、不规则冰块及大冰筏。
- 两只有斑点和苍白吻部的港海豹：呼吸、张望、抓挠；冰筏海豹可失衡滑落、游泳并爬回。
- 座头鲸的身体沿头部经过的路径弯曲，始终头部先行；包含喉部褶皱、口线、眼睛、吻部结节、长鳍、背鳍及宽尾鳍。

## 实现

### 水体

JavaScript 在约 **200 × 140** 网格上，以固定 **180 Hz** 子步长求解通量形式的高度场长波方程：

```text
∂²h/∂t² = ∇ · (g · depth ∇h)
```

共享面通量、反射 / 无通量边界、变化水深、阻尼、轻微黏性、CFL 限制、深度相关的波谷限制及体积校正共同保持稳定。波浪绕过岛屿，在浅水区减速，并在玻璃处反射。柱塞和动物造成的扰动进入实际模拟，而不是在水面着色器中添加装饰性波形。

浮动物体跟随局部水位与平均坡度，有漂移、相互碰撞，以及玻璃 / 浅水避让。动物与水体的耦合使用有界近似；这是高度场长波模型，不是三维 Navier–Stokes 或湿干岸线洪泛模拟。

### 渲染

- 原生 WebGPU / WGSL，无渲染库。
- 不透明 HDR 通道与距离缓冲，4× MSAA。
- 波浪驱动的屏幕空间折射、冷蓝深度吸收、菲涅尔天空反射、水线、侧壁横截面及泡沫。
- 由实时高度场曲率驱动的水下焦散、主光阴影与中性色调映射。
- 程序化极光、星星、柔软透明的喷雾与风驱降雪。
- 响应式布局、可折叠移动控件和至少 44 px 的移动触摸目标。

## 验证

已进行 Node 物理稳定性 / 体积守恒检查，以及 Chrome 原生 WebGPU 浏览器测试，覆盖：

- 按压、拖拽、真实尾流、悬停不激发波浪、玻璃晃荡与果冻回弹。
- 普通涟漪、强波倾覆和“被拿着时不倾覆”。
- 海豹滑落 → 游泳 → 爬回，以及鲸鱼浮起 → 喷雾 → 潜水的完整状态转换。
- 天气模式、暴风雪、暂停的精确冻结、重置与相机控制。
- WGSL 编译、渲染通道、WebGPU 后备卡片、双指缩放。
- 320、360、390 和 480 px 移动布局，无水平溢出。
